# ZeuTab Site

Static website for ZeuTab and its Chrome Web Store privacy policy.

## Deploy with GitHub Pages
1. Create a public repository named `zeutab-site`.
2. Upload these files to the repository root.
3. Settings → Pages → Deploy from a branch → `main` / `(root)`.
4. Set the custom domain to `zeutab.zeuleg.dev`.
5. In DNS, create a CNAME: `zeutab` → `zeuleg.github.io`.
6. Enable HTTPS once available.

Chrome Web Store privacy policy URL:
`https://zeutab.zeuleg.dev/privacy/`

No JavaScript, analytics, trackers, remote fonts, or third-party assets are used.
