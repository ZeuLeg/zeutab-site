Overview

ZeuTab is a Chrome extension whose single purpose is to keep exactly one real Chrome New Tab available at the far right of each normal browser window.

Data accessed

ZeuTab uses Chrome's tabs permission to access tab information needed to manage browser tabs. In particular, it may inspect a tab's URL or pending URL locally to determine whether that tab is Chrome's New Tab page and to manage tab position and focus.

ZeuTab does not collect page content, form data, passwords, personal communications, or browsing history for analytics, advertising, profiling, or any other secondary purpose.

Local session storage

ZeuTab uses chrome.storage.session only for temporary recovery information needed when its Manifest V3 service worker restarts.

This recovery information contains numeric browser window/tab identifiers such as the last known active tab identifier. ZeuTab does not persist visited URLs, page content, or browsing history in extension storage.

Chrome manages session storage in memory. It is cleared when the extension is disabled, reloaded, or updated, and when the browser restarts.

Data transmission and sharing

ZeuTab does not transmit browser tab data, URLs, browsing activity, or other user data to the developer or to any external server.

ZeuTab does not sell, share, or transfer user data to third parties and does not use user data for advertising, tracking, profiling, creditworthiness, or personalized recommendations.

Remote code

ZeuTab does not download or execute remotely hosted code. All executable extension code is included in the installed extension package.

Limited Use

ZeuTab's access to browser information is limited to its single user-facing purpose: maintaining the New Tab anchor and related tab-position and focus behavior.

ZeuTab's use of information received from Chrome APIs is intended to comply with the Chrome Web Store User Data Policy, including its Limited Use requirements.

Changes to this policy

If ZeuTab's data practices change, this privacy policy will be updated before those changes are released.

Contact

For privacy questions or support, contact support@zeuleg.dev.

Genel Bakış

ZeuTab, her normal Chrome penceresinin en sağında tam olarak bir gerçek Chrome Yeni Sekme sayfasını hazır tutmak için geliştirilmiş bir Chrome uzantısıdır.

Erişilen veriler

ZeuTab, sekmeleri yönetmek için gerekli bilgilere erişebilmek amacıyla Chrome'un tabs iznini kullanır. Özellikle bir sekmenin Chrome'un Yeni Sekme sayfası olup olmadığını yerel olarak belirlemek ve sekme konumu ile odağını yönetmek için sekmenin URL veya bekleyen URL bilgisini inceleyebilir.

ZeuTab; analiz, reklam, profilleme veya başka bir ikincil amaç için sayfa içeriği, form verisi, parola, kişisel iletişim veya tarama geçmişi toplamaz.

Yerel oturum depolaması

ZeuTab, chrome.storage.session alanını yalnızca Manifest V3 servis worker'ı yeniden başladığında gereken geçici kurtarma bilgileri için kullanır.

Bu bilgiler, son bilinen aktif sekme kimliği gibi sayısal tarayıcı pencere/sekme kimliklerinden oluşur. ZeuTab ziyaret edilen URL'leri, sayfa içeriğini veya tarama geçmişini uzantı depolamasında kalıcı olarak saklamaz.

Oturum depolaması Chrome tarafından bellekte yönetilir; uzantı devre dışı bırakıldığında, yeniden yüklendiğinde veya güncellendiğinde ve tarayıcı yeniden başlatıldığında temizlenir.

Veri aktarımı ve paylaşımı

ZeuTab tarayıcı sekmesi verilerini, URL'leri, tarama etkinliğini veya diğer kullanıcı verilerini geliştiriciye ya da herhangi bir harici sunucuya aktarmaz.

ZeuTab kullanıcı verilerini üçüncü taraflara satmaz, paylaşmaz veya devretmez; reklam, izleme, profilleme, kredi değerliliği veya kişiselleştirilmiş öneriler amacıyla kullanmaz.

Uzak kod

ZeuTab uzaktan barındırılan kod indirmez veya çalıştırmaz. Çalıştırılabilir tüm uzantı kodu, yüklenen uzantı paketinin içinde bulunur.

Sınırlı Kullanım

ZeuTab'ın tarayıcı bilgilerine erişimi yalnızca tek kullanıcıya dönük amacıyla sınırlıdır: Yeni Sekme anchor'ını ve buna bağlı sekme konumu/odak davranışını korumak.

ZeuTab'ın Chrome API'lerinden aldığı bilgileri kullanımı, Limited Use gereksinimleri dahil Chrome Web Store Kullanıcı Verileri Politikası'na uygun olacak şekilde tasarlanmıştır.

Değişiklikler

ZeuTab'ın veri işleme uygulamaları değişirse, bu gizlilik politikası ilgili değişiklikler yayınlanmadan önce güncellenecektir.

İletişim

Gizlilik soruları veya destek için support@zeuleg.dev adresinden iletişime geçebilirsiniz.
